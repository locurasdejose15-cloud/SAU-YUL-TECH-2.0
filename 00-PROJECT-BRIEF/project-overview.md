# Descripción del proyecto

Sau Yul-Tech es un ecosistema de agrotecnología orientado inicialmente a pequeños y medianos productores ganaderos de Nicaragua. Integra gestión web, aplicación móvil, administración, dispositivos IoT, conectividad, análisis de datos y servicios de soporte en una misma propuesta.

El problema de los registros dispersos y las dificultades de seguimiento se validará con productores. El proyecto está en planificación y definición. Consulta el [Project Brief v1.0](project-brief.md) para conocer el propósito y los componentes previstos.
