# Descripción del proyecto

Sau Yul-Tech explora herramientas digitales para que los equipos ganaderos puedan consultar el historial de cada animal y coordinar el trabajo de finca. La hipótesis es que los registros dispersos dificultan recuperar datos de salud, reproducción y producción cuando se necesitan. Conviene validarla observando cómo trabajan las fincas y qué decisiones toman con esos datos.

## Flujo propuesto

Un responsable registra la finca y sus animales. El personal autorizado añade eventos a la ficha de cada animal y consulta su historial. Si se aprueba una integración IoT, las mediciones de un dispositivo vinculado podrían alimentar el monitoreo y las alertas.

El enfoque de producto, el mercado y el papel de los dispositivos requieren aprobación. Consulta el [registro de decisiones](../PROJECT-DECISIONS.md).
