# Glosario del proyecto

| Término | Definición de trabajo |
| --- | --- |
| Finca | Unidad de operación ganadera donde se organizan animales y registros. |
| Ficha individual | Registro identificable de un animal y punto de acceso a su historial. |
| Evento ganadero | Observación o acción fechada asociada a un animal, como una vacuna o tratamiento. |
| Collar inteligente | Dispositivo candidato a registrar y transmitir mediciones de un animal. |
| IoT | Conjunto de dispositivos conectados que capturan o transmiten datos. |
| Telemetría | Mediciones enviadas por un dispositivo para su consulta posterior. |
| Alerta | Aviso generado a partir de una condición definida. |
| MVP | Primera versión utilizable con el alcance mínimo necesario para validar una necesidad prioritaria. |
